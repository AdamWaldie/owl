# Owl source model

"BarnOwl" by BloodTigerWolfSketchF, Sketchfab Free Standard licence (see /CREDITS.md).
Download it from Sketchfab (glTF) and place it here:

    source/owl/owl.glb
    source/owl/textures/gltf_embedded_0.png, gltf_embedded_1.png

These files are git-ignored: the licence does not allow redistributing them on their own.

2,840 triangles, two materials (FeatherAndFur, BakedBarnOwl), 1024x1024 textures,
skinned to a ~240-bone rig. Run the prep script with `--tris 3000`, and a second pass
with `--tris 1000` for the distance LOD.
